## Deskripsi Repository
Repository ini dibuat untuk memenuhi tugas dokumentasi kegiatan Day 1 Proyek Workshop. Seluruh catatan pembelajaran, rangkuman materi, serta refleksi pribadi disimpan secara daring pada repository ini menggunakan platform GitHub.

## Tujuan Repository
1. Sebagai sarana penyimpanan dan pengelolaan dokumentasi kegiatan workshop secara digital.
2. Melatih pemanfaatan Git dan GitHub untuk manajemen proyek dan portofolio.
3. Menyediakan catatan yang terstruktur terkait materi harian workshop.

## Informasi Kegiatan Workshop
* **Kegiatan:** Day 1 Proyek Workshop
* **Fokus Pembelajaran:** Pengenalan alat pengembangan, manajemen repository, dan eksplorasi lingkungan kerja pemrograman.

---

## Dokumentasi Kegiatan Workshop

### 1. Rangkuman Materi
* Pengenalan dasar penggunaan Git dan integrasinya dengan Visual Studio Code.
* Konfigurasi lingkungan pengembangan lokal dan manajemen *source control*.
* Pengenalan platform dan alur kerja pengembangan berbasis kolaborasi daring.

### 2. Poin-Poin Penting / Pengetahuan Baru
* Memahami cara melakukan inisialisasi, *commit*, dan publikasi *repository* langsung dari VS Code maupun menggunakan command line.
* Mengetahui pentingnya file `README.md` sebagai dokumentasi utama sebuah proyek open-source atau tugas.

### 3. Pendapat Pribadi (Refleksi Day 1)
Day 1 Proyek Workshop ini sangat seru dan membuka wawasan baru, terutama terkait praktik langsung penggunaan perangkat modern seperti Git/GitHub dan lingkungan pengembangan yang terintegrasi. Meskipun sempat ada kendala teknis kecil saat konfigurasi awal, proses penyelesaiannya justru memberikan pengalaman troubleshooting yang sangat bermanfaat untuk dunia perkuliahan ke depannya.s
