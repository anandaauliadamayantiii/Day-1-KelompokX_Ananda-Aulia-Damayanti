## Dokumentasi Kegiatan Workshop

### 1. Rangkuman Materi
* **Prompt Engineering:** Cara merancang instruksi kepada AI agar menghasilkan respon yang akurat dan relevan. Struktur prompt yang baik mencakup 4 elemen utama: **Role** (peran AI), **Task** (tugas spesifik), **Context** (latar belakang), dan **Format** (bentuk keluaran yang diinginkan).
* **Git vs GitHub:** **Git** adalah *Version Control System* (DVCS) lokal yang dibuat oleh Linus Torvalds untuk melacak perubahan kode. Sedangkan **GitHub** adalah platform berbasis web untuk menyimpan repository secara daring dan mendukung kolaborasi tim.
* **Git Workflow:** Alur kerja perubahan kode bergerak dari *Working Directory* -> *Staging Area* -> hingga tersimpan di dalam *.git directory* (Repository) melalui perintah `git add` dan `git commit`.
* **Perintah Penting Git & GitHub:** 
  * `git init` (memulai repository baru)
  * `git add .` (memindahkan file ke *staging area*)
  * `git commit -m "pesan"` (menyimpan perubahan)
  * `git push origin main` (mengirim kode lokal ke GitHub)

### 2. Poin-Poin Penting / Pengetahuan Baru
* Pentingnya memberikan konteks yang jelas dan spesifik saat meminta bantuan AI (seperti membuat *Student Task Planner*) agar kode yang dihasilkan lebih minim kesalahan.
* Memahami mekanisme autentikasi menggunakan SSH Key (`ssh-keygen`) dan integrasi langsung antara terminal, VS Code, serta GitHub.
